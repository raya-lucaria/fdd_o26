# Introducción

Esta unidad hace dos cosas. La primera es explicar el funcionamiento del curso:
qué se estudia, cómo se evalúa, dónde vive el material y qué se espera de ti
desde la primera semana. La segunda es dar el mapa conceptual del semestre —el
pipeline de datos— para que cada módulo posterior se entienda como respuesta a un
problema concreto y no como una herramienta suelta que hay que aprender porque sí.

El orden importa. Casi todo lo que veremos después —la terminal, Git, Docker,
Python, la concurrencia— existe en este curso porque algo del viaje de los datos
lo exige. Vale la pena ver el viaje completo antes de bajar a las piezas.
