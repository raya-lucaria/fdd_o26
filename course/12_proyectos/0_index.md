# Los proyectos del curso

Son dos proyectos. **No son tareas**: ambos se presentan en persona, con la demo funcionando.

> [!WARNING]
> **ATENCIÓN: el día de la presentación está prohibido trabajar o seguir haciendo cosas mientras las demás personas exponen su página personal o su proyecto. Pongan atención a sus compañeros.**

**Antes de cada presentación, el scan y las entregas se pausan.** Lo que esté entregado en ese momento es lo que se presenta.

::: table {#proy-resumen title="Los dos proyectos"}

| | Página personal | Proyecto final |
|---|---|---|
| Página | [[pagina-personal]] | [[proyecto-final]] |
| Quién | Individual | Equipo de 1 o 2 (otro tamaño, hablarlo conmigo) |
| Dónde vive | GitHub Pages | Repo público en GitHub, con Docker |
| Entrega | Por definirse | El día del examen final |
| Branch | `tarea-12-pagina` | `tarea-12-proyecto-final` |
| Carpeta | `estudiantes/<tu-login>/pagina/` | `estudiantes/<tu-login>/proyecto-final/` |
| Se presenta | Con la página abierta en vivo | Con demo en vivo, platicando el proceso |

:::

En los dos, **la entrega a GitHub es personal**: cada quien abre su propio pull request desde su fork, con el flujo de [[el-flujo-del-curso]]. En el proyecto final cada integrante del equipo abre el suyo, con los mismos datos del proyecto, para que todo quede identificado por usuario de GitHub.

En ninguno se sube una presentación a GitHub. Con las entregas se arma una tabla ordenada con usuario, nombre y URL, y con ella se pasa a presentar de uno en uno.
