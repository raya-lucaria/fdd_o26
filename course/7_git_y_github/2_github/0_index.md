# GitHub

**Sección 2 de 2** · 6 páginas · unos 140 min

Meta: dos remotes configurados, branches practicadas, y un pull request abierto.

## En corto

- GitHub **no es Git**: es un servidor que hospeda repositorios y les agrega cosas encima.
- Aquí aparecen el **fork** y el **pull request**, lo único de esta unidad que Git no tiene.
- Las branches se practican en el repositorio de verdad, porque el resto del semestre se entrega desde una.
- Acaba con tu pull request abierto y en verde. **Ése es el formato de todas las entregas de aquí a diciembre.**
- Y no es un invento de la materia: es el ciclo con el que se contribuye a **cualquier** proyecto de código abierto.
